# 京东云无线宝 雅典娜 AX6600 (JDCloud AX6600) 专属 iStoreOS 固件云端构建项目

本项目为 **京东云无线宝 雅典娜 AX6600 (Qualcomm IPQ6018 / IPQ6000 平台)** 打造专属最新版本 iStoreOS 固件。

## 📱 硬件参数
- **SoC CPU**: 高通 Qualcomm IPQ6018 / IPQ6000 (四核 1.8GHz ARM Cortex-A53)
- **内存**: 1GB DDR4
- **存储**: 64GB / 128GB eMMC
- **网口配置**: 1x 2.5G 自适应网口 + 4x 千兆 LAN 口
- **无线 Wi-Fi**: QCN9074 / QCN5022 三频 Wi-Fi 6 (AX6600)

## 🚀 编译集成特性
- 原生内置 **iStore 应用商店** 与 QuickStart 快速启动界面
- 内置 **OpenClash** 代理应用
- 内置 **Docker** 容器管理界面 (LuCI App Dockerman)
- 内置 **Samba4** 网络共享与 DiskMan 磁盘管理
- 高通 **Ath11k** Wi-Fi 6 驱动与 QCN9074 固件注入
